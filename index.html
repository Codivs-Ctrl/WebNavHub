☁️ 云同步设置

开启后，网页上「添加 / 编辑 / 删除 / 拖拽排序」站点会自动提交到 GitHub 仓库的 data/sites.js，实现跨浏览器、跨设备的永久保存。

令牌说明：只勾选本仓库的 Contents → Read and write 权限即可，不要给其它权限。 令牌仅保存在本机浏览器，不会写入代码或提交到仓库。 创建入口：Fine-grained tokens

💾 本机文件同步

绑定本机的 data/sites.js 后，每次「添加 / 编辑 / 删除 / 拖拽排序」站点 都会直接写入该文件，不必再手动复制代码。

需要支持 File System Access API 的浏览器（Chrome / Edge 88+）， 并建议用 http://localhost 起服务后访问本页。 本项可与「云同步」同时开启，两边会同时更新。
